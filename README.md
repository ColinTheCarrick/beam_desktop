# Beam Designer

Beam Designer is a Python/Tkinter desktop app for analyzing simply supported and cantilever beams. It displays reactions and shear, moment, and deflection diagrams, provides preliminary stress and deflection checks, and exports results to CSV or PDF.

The section properties are synthetic prototypes; results are unsuitable for real design or construction.

Install Python with Tkinter available, then install the required package, matplotlib (version 3.7 or later):

```sh
python -m pip install -r requirements.txt
```

Start the app:

```sh
python app.py
```
