Point loads

Uniform loads

Point loads: -20 to 20 kip. Uniform loads: -5 to 5 kip/ft. Negative values act upward; positive values act downward. Position sliders run from 0 to the span. Beam self-weight is excluded.

L/360 is a configurable screening default, not a universal design limit. The allowable stress is user-supplied; the app does not derive it from Fy.
